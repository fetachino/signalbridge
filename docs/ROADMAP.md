# SignalBridge roadmap

## Completed

- TV-focused visual system and 16:9 layout
- Home, live monitor, and alert history experiences
- Alert switching with severity and confidence states
- Read-aloud guidance and large-text mode
- Public GitHub repository with automated build verification

## Next

- Add keyboard and remote focus traversal tests
- Add real video fixtures and frame capture
- Add OCR preprocessing and structured alert extraction
- Move shared screens into the Fire TV/Vega project structure

## Later

- Multi-language guidance
- Offline alert processing and replayable evidence logs
- Optional AWS integration with explicit cost controls
- Evaluation dashboard for precision, recall, latency, and failure cases
- Demo video and final Devpost submission materials
