# Contributing to SignalBridge

SignalBridge is a portfolio and hackathon project focused on accessible TV experiences. Contributions should preserve the core principles of clarity, evidence, user control, and responsible alert handling.

## Local workflow

```bash
npm install
npm run dev
npm run build
```

## Before opening a pull request

- Keep the 16:9 TV layout usable at a distance.
- Make interactive controls reachable with a remote or keyboard.
- Include accessible labels for icon-only controls.
- Do not present uncertain detections as confirmed facts.
- Update the README or roadmap when a user-facing capability changes.
